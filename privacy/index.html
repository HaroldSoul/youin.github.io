YouIN은 출시 준비 중입니다. AdMob 광고와 UMP 동의 관리는 출시 시 도입 예정이며, 이 정책은 해당 계획과 확인된 카메라 처리 원칙을 구분해 설명합니다.

01. 적용 범위와 현재 상태

이 정책은 YouIN 앱과 공식 홈페이지의 정보 처리 방식을 설명합니다. 앱은 출시 준비 중입니다. 아래에서 광고·동의 관리처럼 도입 예정인 기능은 현재 제공 중인 기능과 구분합니다. 출시 버전의 기능과 실제 처리 방식이 달라지면 공개 전에 이 정책을 업데이트합니다.

이 홈페이지에는 광고 SDK, 방문자 분석 도구, 카메라 기능을 넣지 않았습니다. 언어 선택만 브라우저의 로컬 저장소에 보관할 수 있습니다. 웹사이트를 제공하는 GitHub Pages는 접속 시 IP 주소 등 웹 요청 정보를 자체 정책에 따라 처리할 수 있습니다.

02. 처리하는 정보

  • 게임 중 카메라·사진 정보: 얼굴 반응 효과 및 게임 진행을 위한 영상, 사용자가 촬영하거나 선택한 사진, 임시 얼굴 분석 결과를 기기 안에서 처리합니다.
  • 근거리 플레이 정보: 연결 상대를 찾고 게임을 진행하기 위한 연결 정보 및 플레이 메시지를 참여 기기 사이에서 교환할 수 있습니다.
  • 광고 관련 정보: 출시 시 광고 SDK를 도입하면 광고 식별자, IP 주소, 대략적인 위치, 진단 정보, 광고 상호작용 등이 처리될 수 있습니다. 자세한 내용은 아래 광고 항목에 설명합니다.
  • 지원 문의: 사용자가 자발적으로 제출한 문의 내용과 공개 프로필 등 문의 채널에서 제공하는 정보를 문제 해결에 사용합니다. 얼굴 사진이나 민감한 개인정보를 문의에 포함하지 마세요.

03. 카메라·사진 보관함 권한

카메라 권한은 얼굴 반응 효과와 게임 진행에 필요한 촬영·실시간 처리를 위해 사용합니다. 사진 보관함 접근은 사용자가 게임에 쓸 사진을 직접 선택하는 경우에 사용합니다. 운영체제가 지원하면 필요한 사진만 선택해서 허용할 수 있습니다.

권한은 기기 설정에서 거부하거나 철회할 수 있습니다. 거부하면 해당 권한이 필요한 기능을 사용할 수 없거나 기능이 제한될 수 있습니다. 다른 사람의 사진은 당사자가 동의한 경우에만 사용하세요.

04. 온디바이스 얼굴 처리

카메라 영상과 촬영·선택한 사진은 얼굴 반응 효과 및 게임 진행을 위해 기기 안에서 처리합니다. 원본 영상과 사진을 YouIN 서버로 업로드하거나 영구 저장하지 않습니다. 임시 얼굴 분석 데이터는 한 라운드가 끝나거나 게임을 종료하면 폐기하는 방향으로 설계했습니다.

신원, 성별, 나이, 인종, 피부색 같은 민감한 속성을 추론하지 않습니다. “딱 걸렸어”는 실제 과학적 거짓말 탐지기가 아닌 오락용 게임입니다. 취업·법률·의료·금융·관계 감시 등 중요한 판단에 사용할 수 없습니다. “누가 더?” 결과는 매 게임 달라지는 가상의 NPC 취향이며 객관적인 외모 평가가 아닙니다.

이 카메라 처리 원칙은 모든 데이터가 기기 밖으로 전송되지 않는다는 뜻은 아닙니다. 근거리 게임 메시지, 도입 예정인 광고 SDK, 홈페이지 호스팅에는 별도의 정보 처리가 적용됩니다.

05. 근거리 기기 연결

라스트 킥의 근거리 플레이는 Nearby Connections를 사용할 수 있습니다. 사용자가 근거리 플레이에 참여하면 주변 기기를 찾고 연결하기 위한 정보와 플레이 메시지를 기기 사이에서 교환합니다. 운영체제와 기능에 따라 Bluetooth, Wi-Fi, 근처 기기 또는 로컬 네트워크 권한 등이 필요할 수 있습니다.

Google Play 서비스의 Nearby SDK는 연결 성능과 기기 정보 등 사용 진단 정보를 처리할 수 있습니다. Google 안내에 따르면 지원되는 Android 기기의 Google 설정에서 사용 및 진단 정보 공유를 관리할 수 있습니다. 연결 메시지와 카메라 원본의 처리는 서로 구분되며, 근거리 연결을 위해 카메라 원본을 전송하지 않습니다.

06. 광고와 동의 관리 — 도입 예정

서비스 출시 시 Google AdMob 광고와 Google User Messaging Platform(UMP) 동의 관리를 도입할 계획입니다. 아직 이 홈페이지에 해당 광고 SDK를 탑재하지 않았으며, 이 안내는 출시 시 앱에 적용될 예정인 처리 방식을 설명합니다.

Google Mobile Ads SDK는 광고 제공, 성과 측정, 진단 및 부정행위 방지 등을 위해 광고 식별자와 기타 기기 식별자, IP 주소, IP 주소 등에서 유추한 대략적인 위치, 진단 정보, 광고 노출·클릭 등 상호작용 정보를 처리할 수 있습니다. 실제 처리 항목은 운영체제, SDK 버전, 광고 설정 및 동의 상태에 따라 달라집니다. 카메라 데이터의 기기 내 처리가 광고 데이터까지 기기 내에 머문다는 뜻은 아닙니다.

필요한 지역과 상황에서 UMP로 개인정보 선택 및 동의를 안내하고, 변경이 필요한 경우 앱 내 개인정보 옵션을 제공할 계획입니다. 동의를 거부해도 모든 정보 처리가 중단된다고 단정할 수는 없습니다. 제한적 광고나 부정행위 방지에 필요한 처리가 적용될 수 있으므로 실제 동의 화면과 Google 정책을 함께 확인하세요.

07. 아동과 보호자 안내

출시 시 앱스토어의 연령 등급과 이용 안내를 확인하세요. 미성년자는 보호자와 함께 카메라·사진 권한, 근거리 플레이 및 광고 관련 선택을 검토하는 것이 좋습니다. 보호자는 어린이의 기기 권한과 이용을 관리하고, 다른 사람의 사진을 동의 없이 사용하거나 공개하지 않도록 도와주세요.

거주 지역의 기준상 보호자 동의가 필요한 경우 보호자와 함께 이용 여부를 결정하세요. 아동의 개인정보가 의도치 않게 문의 등으로 제공되었다고 판단되면 지원 창구를 통해 알려주세요. 공개 문의에 아동의 이름·사진·연락처를 추가로 게시하지 마세요.

08. 데이터 보관과 삭제

카메라 원본 영상·사진은 서버에 업로드하거나 영구 저장하지 않습니다. 게임 처리 중 임시 얼굴 분석 데이터는 라운드 종료 또는 게임 종료 시 폐기하도록 설계했습니다. 사용자의 기존 사진 보관함 원본은 앱에서 선택했다고 삭제되지 않습니다.

홈페이지의 언어 설정은 브라우저 저장소를 삭제하면 지울 수 있습니다. 문의 정보는 문제 해결과 후속 대응을 위해 필요한 동안 이용하며, 공개 게시물 보관·삭제는 해당 문의 서비스의 기능과 정책에도 영향을 받습니다. 게시물 수정·삭제를 직접 진행하거나, 민감정보를 반복해서 적지 말고 삭제를 요청하세요.

도입 예정인 Google 광고 및 Nearby 서비스가 처리하는 정보의 보관 기간은 각 제공자의 정책과 설정에 따릅니다. YouIN이 해당 제공자의 모든 데이터를 직접 삭제할 수 있다고 보장하지 않습니다.

09. 제3자 서비스

서비스별 역할과 공식 안내는 다음과 같습니다.

  • Google 개인정보처리방침 — AdMob·UMP 및 Google 제공 서비스의 정보 처리.
  • Google Mobile Ads SDK 데이터 공개 안내 및 UMP 안내 — 도입 예정인 광고·동의 관리.
  • Nearby Connections 안내 — 근거리 연결과 사용 진단 정보.
  • GitHub 개인정보처리방침 — 홈페이지 호스팅 및 현재의 공개 문의 창구.

각 링크로 이동하면 해당 제공자의 서비스 및 정책이 적용됩니다. Google은 광고·진단 정보를 자체 서버에서 처리할 수 있으며, 처리가 이루어지는 국가와 세부 방식은 Google 정책에 설명됩니다.

10. 사용자의 선택권

  • 기기 설정에서 카메라·사진·근처 기기·로컬 네트워크 권한을 변경할 수 있습니다.
  • 라운드를 종료하거나 앱을 종료하여 해당 게임의 얼굴 처리를 중단할 수 있습니다.
  • 출시 후 광고 동의 변경 기능이 제공되는 경우 앱 내 개인정보 옵션에서 선택을 다시 검토할 수 있습니다. 운영체제에서 광고 식별자·추적 관련 설정도 관리할 수 있습니다.
  • 지원되는 기기의 Google 설정에서 사용 및 진단 정보 공유를 관리할 수 있습니다.
  • 브라우저 저장소를 지우거나 KO/EN 전환을 사용해 홈페이지 언어 설정을 바꿀 수 있습니다.
  • 문의 정보에 대한 확인·수정·삭제 요청은 지원 창구를 이용하세요. 요청 범위와 해당 서비스에서 가능한 조치를 확인해 안내합니다.

11. 정책 변경

기능, SDK, 실제 정보 처리 방식이 달라지면 이 페이지와 최종 수정일을 갱신합니다. 중요한 변경이 있을 때는 홈페이지 또는 앱 내 안내 등 적절한 방법으로 알릴 예정입니다. 출시 전에는 실제 앱 동작, 스토어 개인정보 공개 내용 및 이 정책이 일치하는지 다시 확인합니다.

12. 문의 방법

YouIN 개인정보 처리 및 사용자 지원 문의는 아래 창구를 이용하세요. 전용 지원 이메일은 아직 공개하지 않았습니다.

문의 남기기

현재 임시 문의 창구는 GitHub Issues입니다. 작성 시 GitHub 계정이 필요하며 게시 내용은 공개됩니다. 얼굴 사진, 개인 연락처 등 민감한 정보는 올리지 마세요.
